## 🚀 Sobre Mim

Desenvolvedor **Full Stack** focado na construção de aplicações modernas, escaláveis e com identidade visual forte.

Atualmente trabalho principalmente com:
- React
- Next.js
- TypeScript
- Node.js
- TailwindCSS

Tenho interesse especial em criar experiências digitais que combinem:
- performance real
- interfaces modernas
- acessibilidade
- animações fluidas
- arquitetura organizada
- boa experiência de usuário

📚 Atualmente aprofundando conhecimentos em:
- Arquitetura Full Stack
- Performance Web
- Engenharia de Software
- Banco de Dados
- Ciência de Dados e IA

♿ Também tenho grande interesse em acessibilidade digital, porque acredito que boas aplicações devem ser utilizáveis por qualquer pessoa.

🎯 Gosto de desenvolver projetos que resolvam problemas reais, transformar ideias em produtos funcionais e evoluir continuamente tanto no lado técnico quanto no design das aplicações.

🌎 Aberto para:
- oportunidades remotas
- networking
- colaborações
- projetos em equipe
- desenvolvimento de produtos digitais
